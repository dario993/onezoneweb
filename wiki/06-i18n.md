# Internazionalizzazione (i18n)

## Architettura

```
I18nService → I18nFileService → assets/i18n/{de,en,fr,it}.json
```

**Lingue supportate**: `de` (default), `en`, `fr`, `it`
**Mappatura numerica**: `de→1`, `fr→2`, `it→3`, `en→4`

---

## File di Traduzione

**Formato**: JSON gerarchico in `src/assets/i18n/`

```json
{
  "menu": { "home": "Home", "lang": "Lingue" },
  "login": { "email": "Email", "button": "Login" }
}
```

---

## I18nPipe

**File**: [i18n.pipe.ts](../src/app/pipes/i18n.pipe.ts)

```html
<h1>{{ 'menu.home' | i18n }}</h1>
```

```typescript
transform(value: string): string {
  const keys = value.split('.');
  return this.i18nService.getTranslation(...keys);
}
```

---

## Cambio Lingua Runtime

```typescript
this.storageService.setItem('selectedLanguage', 'it');
const langFile = this.i18nFileService.getLanguageFile('it');
this.i18nService.loadLanguage(langFile);
this.i18nService.currentLanguage = 'it';
```
